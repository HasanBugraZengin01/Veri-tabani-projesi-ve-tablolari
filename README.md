# Veri-tabani-projesi-ve-tablolari
Veri tabanı yönetimi dersi kapsamında hazırladığımız varlık ilişkileri diyagramları, Excel dosyalarını ve SQL kodlarını içeriyor.
"xlsx" uzantılı dosyalar, veri setimizdeki bilgileri ilişkiler temelinde gösteriyor. Örneğin, "Product-Customer Table" dosyasında alınan ürünleri ve bu ürünleri alan müşteriye ait bilgiler gösteriliyor.
"Farm Table.docx" belgesinde, çiftlikteki ürünlerin, müşterilerin, tedarikçilerin, sertifikasyon gibi kayıtlarının tutulduğu belgedir.
"sql" uzantılı dosyalarda ise "xlsx" uzantılı belgelerde tuttuğumuz tabloları Microsoft SQL Server'a aktarırken yazdığımız SQL kodları vardır. 
"SQL Codes.sql" yazılı dosya, Microsoft SQL Server'da tablo yapmak için yazılan kodları göstermektedir.
